# UI primitives

Small, domain-neutral building blocks for forms, layout, overlays, and data display.

| Component | Use for |
| --- | --- |
| `Button` | Actions (`primary`, `secondary`, `danger`, `ghost`) |
| `Input` | Single-line text fields |
| `Select` / `SelectOption` | Dropdown choices |
| `Textarea` | Multi-line text |
| `Card` (+ header, content, footer) | Grouped content panels |
| `Dialog` | Modal overlays with title and close control |
| `Table` (+ header, body, row, head, cell) | Tabular data |

Reuse these primitives when they fit. Compose them instead of duplicating equivalent markup and styles. When a requirement needs different behavior or structure, build a focused component rather than stretching a primitive.
